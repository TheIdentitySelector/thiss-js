SeamlessAccess Upgrade Test Page

This page allows testing all combinations of entry point versions during a deployment upgrade. Use this to verify that users won't experience issues when some components are served from different server nodes during the upgrade process.

Current (PREV_VERSION) Entry point from /
New (VERSION) Entry point from /new/
Note: The /new/ paths are only available during step 1 deployment (PRE_RELEASE=true). After step 2 deployment, all paths serve the new version.

Direct Entry Point Links

You can also test the entry points directly:

  • Current Version (from /):
  • /ds/ - Discovery Service
  • /cta/ - Call-to-Action (embedded component)
  • /ps/ - Persistence Service (iframe)
  • /result/ - Result page
  • New Version (from /new/):
  • /new/ds/ - Discovery Service
  • /new/cta/ - Call-to-Action (embedded component)
  • /new/ps/ - Persistence Service (iframe)
  • /new/result/ - Result page
